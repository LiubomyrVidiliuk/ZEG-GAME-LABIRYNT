Rycerz otrzymuje zadanie odnalezienia starożytnego artefaktu ukrytego głęboko w labiryncie. Aby go zdobyć, musi przejść przez trzy poziomy pełne pułapek, zamkniętych przejść, zagadek i niebezpieczeństw. Z każdym poziomem labirynt staje się coraz trudniejszy. Po pokonaniu wszystkich przeszkód rycerz odnajduje artefakt i kończy swoją misję.
